    Class ObservableString

    An observable that holds a string value. Listeners are notified whenever the value changes.

    Example: guildTagEditor.js

    import { Player, system } from "@minecraft/server";
    import { CustomForm, DataDrivenScreenClosedReason, ObservableString } from "@minecraft/server-ui";

    // Run `/scriptevent example:guildtageditor` in chat to open the form.
    system.afterEvents.scriptEventReceive.subscribe(({ id, sourceEntity }) => {
       if (id !== "example:guildtageditor" || !(sourceEntity instanceof Player)) return;

       const guildTag = new ObservableString("Vanguard", { clientWritable: true });
       guildTag.subscribe((text) => {
           sourceEntity.sendMessage(`Guild tag updated: ${text}`);
       });

       const form = new CustomForm(sourceEntity, "Guild Editor");
       form.textField("Guild Tag", guildTag);

       form.show().then((reason) => {
           if (reason === DataDrivenScreenClosedReason.ServerClosed) {
               sourceEntity.sendMessage("The server closed the guild editor.");
           } else {
               sourceEntity.sendMessage("You closed the guild editor.");
           }
       });
    });

      Remarks

      Gets filtered data from the Observable (only available for strings). In case of failure, it will return an array of TextFilteringError that can provide more context about the filtering process. For testing purposes, the options are available under 'Creator -> Text Filtering' settings menu. This delay is only applied to the getFilteredText function and can be used to simulate network latency when testing.

      Example: filterChatMessage.js

      import { Player, system } from "@minecraft/server";
      import { ObservableString } from "@minecraft/server-ui";

      // Run `/scriptevent example:filterchatmessage` in chat to try this example.
      system.afterEvents.scriptEventReceive.subscribe(({ id, sourceEntity }) => {
      if (id !== "example:filterchatmessage" || !(sourceEntity instanceof Player)) return;

      const chatMessage = new ObservableString("Hello world", { clientWritable: true });

      // Check the string against Minecraft text filtering rules for the player.
      chatMessage.getFilteredText(sourceEntity).then((filteredResult) => {
         if (typeof filteredResult === "string") {
             sourceEntity.sendMessage(`Filtered message: ${filteredResult}`);
         } else {
             sourceEntity.sendMessage("Text filtering blocked the message.");
         }
      });
      });

    subscribe

    • subscribe(callback: (arg0: string) => void): (arg0: string) => void

      Parameters

      • callback: (arg0: string) => void

        A function that receives the new string value each time the observable changes.

      Returns (arg0: string) => void

      Remarks

      Registers a callback to be invoked whenever the observable's value changes. Returns the callback, which can be passed to unsubscribe to remove the listener.

      Write Privilege

      This function can't be called in restricted-execution mode.

      Privilege

      early-execution-allowed - This function can be called in early-execution mode.

      Example: rankTitle.js

      import { Player, system } from "@minecraft/server";
      import { CustomForm, ObservableString } from "@minecraft/server-ui";

      const titles = ["Novice", "Adventurer", "Champion", "Legend"];

      // Run `/scriptevent example:ranktitle` in chat to open the form.
      system.afterEvents.scriptEventReceive.subscribe(({ id, sourceEntity }) => {
      if (id !== "example:ranktitle" || !(sourceEntity instanceof Player)) return;

      const playerTitle = new ObservableString("Novice");
      // `subscribe` returns the callback. Keep it so `unsubscribe` can remove the same listener.
      const listener = playerTitle.subscribe((title) => {
         sourceEntity.sendMessage(`Rank title updated to ${title}.`);
      });

      const form = new CustomForm(sourceEntity, "Player Rank");
      form.button("Unsubscribe", () => playerTitle.unsubscribe(listener));
      form.button("Subscribe", () => playerTitle.subscribe(listener));

      // Pick a random title every 2 seconds (40 ticks) so the listener receives updates while subscribed.
      const intervalId = system.runInterval(() => {
         playerTitle.setData(titles[Math.floor(Math.random() * titles.length)]);
      }, 40);

      // `show` resolves when the player closes the form. Stop the changes then.
      form.show().then(() => system.clearRun(intervalId));
      });
