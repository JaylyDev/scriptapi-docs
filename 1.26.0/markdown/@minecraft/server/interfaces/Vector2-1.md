# Interface: Vector2

Represents a two-directional vector.

## Examples

```js
const vec2 = { x: 0, y: 0 };
```

```ts
import { Vector2 } from "@minecraft/server";

const vec2: Vector2 = { x: 0, y: 0 };
```

## Properties

### x

> **x**: `number`

#### Remarks

X component of the two-dimensional vector.

***

### y

> **y**: `number`

#### Remarks

Y component of the two-dimensional vector.
