What is Minecraft Script API?

Minecraft Script API is Mojang's official JavaScript/TypeScript API for Minecraft Bedrock Edition. It lets addon creators interact with a Minecraft world programmatically - spawning entities, manipulating blocks, responding to player events, building custom modal forms, and persisting data in world storage.

This documentation site is independently maintained and covers all stable, beta, and preview modules, keeping pace with each Minecraft release.

Available Modules

Available modules in the Minecraft Script API as of Minecraft 1.26:
